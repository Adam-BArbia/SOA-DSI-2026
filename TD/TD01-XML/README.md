# TD1 — Structuration, validation et échange de données (XML)

- [Énoncé](TD1.pdf) · [Correction fournie](TD1-Correction.pdf) · [Réponses détaillées](reponses.md)
- `exemples/` conserve les documents XML, la DTD et le XSD répondant aux exercices.
- Vérification recommandée : `xmllint --noout --dtdvalid exemples/universite.dtd exemples/universite-corrige.xml` et `xmllint --noout --schema exemples/etudiant.xsd exemples/etudiant-valide.xml`.

⚠️ **Attention** : la correction officielle du TD1 semble traiter une version différente de l'énoncé pour certains exercices. Nos réponses sont fondées sur le PDF de l'énoncé ; les écarts sont explicités.
